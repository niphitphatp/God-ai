### บทคัดย่อ
รายงานนี้เสนอการพัฒนาระบบจำแนกท่าทางมือในการเล่นเป่ายิ้งฉุบ (ค้อน กรรไกร กระดาษ) แบบ Real-time โดยใช้เทคโนโลยี Computer Vision และ Machine Learning กระบวนการพัฒนาครอบคลุมตั้งแต่การเก็บรวบรวมข้อมูลภาพมือที่มีความหลากหลาย การฝึกฝนโมเดล (Model Training) และการประเมินผลด้วยข้อมูลใหม่ (Unseen Data) ผลการดำเนินงานชี้ให้เห็นว่า ระบบสามารถจำแนกท่าทางได้อย่างถูกต้อง โดยประสิทธิภาพและความแม่นยำของโมเดลขึ้นอยู่กับคุณภาพและความหลากหลายของชุดข้อมูลเป็นสำคัญ ซึ่งสามารถนำไปประยุกต์ใช้ในเกมโต้ตอบ และระบบควบคุมด้วยท่าทางมือได้

### วัตถุประสงค์

• เพื่อพัฒนาและฝึกฝนโมเดล AI สำหรับตรวจจับและจำแนกท่าทางมือ (ค้อน กรรไกร กระดาษ) ผ่านกล้องแบบ Real-time
• เพื่อศึกษาและประยุกต์ใช้เทคโนโลยี Computer Vision และ Machine Learning ในการประมวลผลภาพ
• เพื่อนำระบบไปต่อยอดในการพัฒนาเกมโต้ตอบ (Interactive Game) และระบบสั่งงานด้วยท่าทาง (Gesture Control)
